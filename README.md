# EmbedSocial — Responsive Website

A modern, responsive website recreated using **HTML5** and **CSS3**, inspired by the EmbedSocial website.

## Overview

This project focuses on recreating a multi-section landing page while practicing frontend development skills and responsive web design.

## Features

- Clean and modern user interface
- Fully responsive layout
- Desktop, tablet, and mobile screen support
- Multiple content and feature sections
- Custom layouts and styling using CSS

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## What I Learned

- Building layouts with Flexbox and CSS Grid
- Creating responsive designs using media queries
- Working with spacing, alignment, and positioning
- Improving page structure and styling with HTML and CSS

## Project Status

Completed as an HTML and CSS practice project. Further improvements may be added as I continue learning frontend development.


Created with ❤️ while learning HTML & CSS.
